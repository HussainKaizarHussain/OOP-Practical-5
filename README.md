# OOP-Practical-5: Single and Multilevel Inheritance

## Purpose & Aim
- **Aim**: To understand base and derived classes and how data and behaviour can be reused[cite: 1].
- **Question**: Implement a university-management example using inheritance: Person → Student → GraduateStudent[cite: 1].

---

## What to Do
- Create a Person base class with common information such as name and age[cite: 1].
- Create a Student class derived from Person with student ID and course details[cite: 1].
- Create a GraduateStudent class derived from Student with a research topic or supervisor name[cite: 1].
- Add constructors and display functions in the relevant classes[cite: 1].
- Demonstrate single inheritance using Person → Student, and multilevel inheritance using all three classes[cite: 1].
- Create objects and explain which inherited members are available to each derived class[cite: 1].
